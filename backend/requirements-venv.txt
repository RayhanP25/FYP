# Backend requirements for a plain venv (no conda). Works on RTX 50-series (e.g. 5060 Ti)
# and older NVIDIA cards. Needs Python 3.10 (3.11 also works) and NVIDIA driver 570+.
# The CUDA runtime ships inside the torch wheels; no CUDA toolkit or Visual Studio needed.
#
# Setup with uv (it fetches its own Python 3.10; nothing installed system-wide), from backend\:
#   uv venv --python 3.10 .venv
#   .venv\Scripts\activate
#   uv pip install -r requirements-venv.txt --index-strategy unsafe-best-match
#   uv pip install --no-deps mmpose==1.3.2
#
# mmpose goes in with --no-deps because it asks for chumpy, which fails to build and is
# never used. mmcv is mmcv-lite (no compiled ops); backend/mmcv_ext_shim.py supplies the
# one op the person detector needs (NMS) through torchvision.
#
# Check:
#   python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
